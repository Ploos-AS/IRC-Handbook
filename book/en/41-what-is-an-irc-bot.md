# What is an IRC bot?

An IRC bot is fundamentally an IRC client controlled by program logic rather than a person.

```text
normal client: person  -> IRC client -> IRC server
bot:           program -> IRC client -> IRC server
```

Both use the IRC protocol on the wire.

Bots may respond to commands, assist with channel administration, publish notifications, automate tasks or integrate IRC with other systems.

A normal bot is not the same thing as network services such as NickServ or ChanServ, and it is not a bouncer. Services, bouncers and bots occupy different roles even when they happen to run on the same infrastructure.
