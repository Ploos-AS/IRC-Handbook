# What is a shell account?

A **shell account** is a user account on a Unix or Linux machine that provides access to a command-line environment, normally over SSH.

In IRC culture, shell accounts have been useful because programs can run on an always-connected remote machine.

```text
your computer -> SSH -> shell server -> Unix shell
```

Depending on the provider and its rules, the account may run terminal IRC clients, tmux or screen, bouncers, bots and small tools.

A shared shell account is not the same as a VPS. You commonly have no root access and share the operating system with other users.

Learning the shell model also teaches SSH, Unix users, processes, file permissions, terminal sessions and remote administration—skills we later reuse on our own Debian VPS.
