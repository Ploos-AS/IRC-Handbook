# Choosing an IRC client

IRC is independent of its user interface, so very different programs can connect to the same network.

Common categories include graphical desktop clients, terminal clients, web clients and mobile clients. Terminal clients such as WeeChat and Irssi are particularly useful for shell accounts and SSH-based setups, while a bouncer is especially helpful for devices that cannot maintain a permanent connection.

For a modern setup, look for TLS certificate validation, SASL, multiple-network support, appropriate IPv6 support, IRCv3 features, reliable reconnect behaviour and safe credential handling.

The client is replaceable. You can start graphically, later use a terminal client on a shell server, or connect several different clients to the same bouncer. In this book the client is a tool, not the platform itself.
